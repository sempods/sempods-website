# UC4 — Social Coordination

**Friends coordinate plans through shared pod data.**

Users share activity ideas ("Kino heute Abend?") and see public events from
subscribed pods. Combines personal planning with public event discovery.

## What it enables

- Social planning without a central platform
- Each person's data stays in their pod
- Aggregation of events from multiple independent pods
- Future: pod-to-pod sharing via Web Identity Access

## What exists today

The w2d2d app ("What to do today?") with real users. Currently hybrid: ideas
via REST API, events via RDF from pods. Migration path: ideas become RDF
resources in personal pods.

## Why this matters

WhatsApp groups are the current "social coordination tool" — chaotic, no
structure, no integration with event data. A pod-based approach combines
structured event data with social interaction, all under user control.
